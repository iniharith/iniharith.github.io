COLOPHON / HOW THIS SITE WORKS

COLOPHON

ONE SHADER PIPELINE · ZERO FRAMEWORKS · NO BUILD STEP

01 — THE TRICK

The dragonfly on the homepage is not ASCII art someone drew. It is a real-time 3D model rendered offscreen, then re-drawn as characters by a fragment shader.

A DRACO-compressed .glb loads into Three.js and renders to an offscreen WebGLRenderTarget. A fullscreen quad samples that texture, quantizes it into cells, converts each cell's luminance into a character index, and looks up the matching glyph from an atlas drawn onto a canvas at runtime. Part of every visit to this page is literally rendered text.

02 — SHADERS

Two custom GLSL programs do the work. Nothing about the materials is stock.

MODEL FRAGMENT
Luminance comes from dot-product lighting on recomputed normals, remapped into an acid-green palette with per-model brightness, normal strength, and color uniforms.
ASCII POST
Splits the frame into cells (size tracks device pixel ratio), maps luminance to a glyph index, samples the atlas, and modulates alpha so bright surfaces dissolve into dense glyphs.
GLYPH ATLAS
The character set * _<>,./O#SF+ is drawn once onto a canvas texture at startup — no image assets involved.

03 — MOTION

Scroll is the only timeline. Everything animates as a function of where you are on the page.

Scroll progress eases the camera along a path baked into the model through two empty marker objects (camera-follow, camera-lookAt), while wing-flap frequency accelerates as you descend. Lenis smooths wheel input, parallax and fluid transforms are batched into a single requestAnimationFrame loop, sections reveal through IntersectionObserver, and prefers-reduced-motion switches the whole show off.

04 — STACK

Boring infrastructure on purpose, so the interesting part can be the pixels.

FRAMEWORK
None. Hand-written HTML, CSS, and ES modules.
RENDERER
Three.js, vendored locally behind an import map — no CDN dependency at runtime.
SCROLL
Lenis for smooth wheel input, native behavior preserved as fallback.
HOSTING
GitHub Pages, static files only.
BUILD STEP
There isn't one. What is committed is what ships.
