OVERVIEW

Kampung Cetak moves a Malaysian printing shop online: customers pick products, upload artwork, and order without a single phone call.

The platform is built in TypeScript with an order pipeline covering quoting, artwork review, production status, and payment — replacing WhatsApp-and-spreadsheet workflows.

HIGHLIGHTS

  • End-to-end online ordering for custom print jobs
  • Artwork upload and review built into the order flow
  • Production dashboard that mirrors real shop state
