# Ini Harith Portfolio

Static portfolio for [iniharith.github.io](https://iniharith.github.io/).

## Preview

Open `index.html` directly or run any static file server from this directory.

## Publish

Create the public repository `iniharith/iniharith.github.io`, push these files to its `main` branch, then select **Deploy from a branch** and `/ (root)` in GitHub Pages settings.
